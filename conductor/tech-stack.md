# Technology Stack

## Core Language & Environment
- **Language:** Python (3.x)
- **Environment Management:** Virtual Environment (`.venv`)

## Drone Control & Communication
- **DJITelloPy:** Used for low-level communication and flight commands with the DJI Tello drone.
- **Python-Dotenv:** Managing project-specific environment variables and configurations.

## Vision & AI
- **OpenCV-Python:** Primary library for image processing, camera calibration, and video streaming.
- **Ultralytics (YOLO):** Object detection and tracking models (e.g., YOLOv8/v11).
- **ArUco Markers:** Utilized for high-precision vision positioning and localization.
- **ONNX Runtime:** Optimized inference engine for running vision and AI models across platforms.
- **Google Generative AI (Gemini):** Integration for AI-enhanced decision-making or natural language capabilities.

## User Interface & User Input
- **Pygame:** Handling real-time input from joysticks and other control devices.
- **Kivy:** Framework for developing the interactive drone control dashboard and GUI components.

## Data & Project Management
- **NumPy:** Numerical computations for vision and flight data processing.
- **Git:** Version control and collaboration.
